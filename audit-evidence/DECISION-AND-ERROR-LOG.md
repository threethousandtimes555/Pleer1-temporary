# Pleer1 — журнал решений, проверок и ошибок

> **Назначение:** сохранять проверяемую историю технических гипотез, решений, экспериментов и исправлений в рамках аудита Pleer1.
>
> **Начало хронологии:** 17 ноября 2026 года. Записи до этой даты не реконструируются задним числом. Подтверждённые исторические факты при необходимости оформляются отдельно как справочный контекст, с указанием источника и уровня уверенности.

## Важное предупреждение о репозитории

Этот журнал находится в **Pleer1-temporary — временном публичном репозитории**. Он предназначен для временного аудита и экспериментов, а не для хранения постоянной истории проекта.

- Не добавлять сюда пароли, токены, ключи API, персональные данные, приватные переписки, секреты или иные чувствительные сведения.
- Не переносить изменения из временного репозитория в основной Pleer1 без отдельного согласования.
- Перед удалением временного репозитория согласовать, какие безопасные записи и результаты нужно сохранить в основном проекте.
- Публичные записи должны содержать только информацию, которую допустимо раскрывать всем.

## Правила ведения журнала

1. Фиксируем гипотезы отдельно от подтверждённых фактов.
2. Проверяем выводы ChatGPT и Qwen независимо; совпадение двух моделей само по себе не считается доказательством.
3. Для каждого существенного вывода указываем проверку: исходный код, diff/commit, лог, артефакт CI, скриншот или воспроизводимый тест.
4. Не переписываем первоначальные предположения задним числом. Исправления добавляем новой записью или обновлением статуса с сохранением истории через Git-коммиты.
5. Если данных недостаточно, прямо пишем «не подтверждено» или «нужны дополнительные данные».
6. Отмечаем как ошибки моделей, так и ошибки процесса, тестов и инженерных решений.
7. Записываем успешные решения и регрессии, чтобы не повторять уже пройденные эксперименты.

## Статусы

- **Гипотеза** — возможное объяснение, ещё не проверено.
- **На проверке** — тест или независимый разбор выполняется.
- **Подтверждено** — есть воспроизводимые доказательства.
- **Опровергнуто** — проверка показала, что гипотеза неверна.
- **Частично подтверждено** — верна только часть предположения.
- **Нужны дополнительные данные** — имеющихся доказательств недостаточно.
- **Исправлено и перепроверено** — изменение внесено и повторная проверка прошла.

### Запись №018 — выяснение, почему прежний «найденный трек» запускался

- **Дата:** 18.11.2026
- **Область:** SearchModel / Jamendo / Player playback / корректность старого UI-теста.
- **Уточнение пользователя:** результат «Джем – я молодой вампир vamp» относится к Jamendo, а не подтверждает поиск отдельного YouTube-видео. Отдельно выяснить, почему этот результат вообще запускался.
- **Подтверждённый путь в коде:**
  1. Старый и текущий `SearchModel.run` запускает источники параллельно; если Jamendo включён и задан `client_id`, вызывается `Sources.jamendo`.
  2. `Sources.jamendo` получает из Jamendo API поля `id`, `name`, `artist_name`, `audio` и создаёт `Track(id: "j" + id, ..., url: audio)`.
  3. `Track.tag` определяет префикс `j` как `Jamendo`.
  4. При выборе такого трека `Player.load()` не идёт в YouTube resolver (он вызывается только для ID с префиксом `y`). Для обычного сетевого трека Player берёт `Track.url` и вызывает `start(u, t, streaming: true)`, то есть передаёт прямой аудио-URL Jamendo в AVPlayer.
- **Вывод:** запуск результата объясняется обычным Jamendo streaming path; он не свидетельствует, что YouTube нашёл или запустил эту песню. Старый тест проверял текст совпадения в общей выдаче и не фиксировал source tag, ID или YouTube video ID. Факт запуска — совместим с Jamendo-потоком и не является подтверждением YouTube.
- **Изменение регрессионного теста:** в рабочей ветке commit [e66d0557](https://github.com/threethousandtimes555/Pleer1/commit/e66d0557fad1c2c08b3e7fd081b6814132a8a001) заменил неоднозначный запрос `я молодой вампир vamp` на контрольный запрос `Crystal Castles Concrete`. Проверка по-прежнему требует accessibility identifier `search.result.youtube.track`, который назначается только трекам с YouTube ID-префиксом `y`, без playlist/radio ID.
- **CI:** run #29 [44204680947](https://github.com/threethousandtimes555/Pleer1/actions/runs/44204680947) на предыдущей версии теста ещё выполнялся; run #30 [44205081047](https://github.com/threethousandtimes555/Pleer1/actions/runs/44205081047) на обновлённом запросе находится в состоянии pending. Результаты обоих запусков не подтверждены на момент записи.
- **Статус:** путь воспроизведения Jamendo подтверждён исходниками; YouTube-only regression test уточнён, его CI-результат ожидается.
- **Границы:** изменены только UI-тест в рабочей ветке и этот журнал в публичном временном репозитории. Основной YouTube parser и поисковая логика пока не изменялись; `main`, стабильный checkpoint и PR не тронуты.
